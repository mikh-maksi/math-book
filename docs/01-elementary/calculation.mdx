# Рахування
Що таке рахування?  
Рахування - це співставлення елементів певної групи однотипних об'єктів із певною довідковою множиною (множиною натуральних чисел).  

## Множина натуральних чисел  
Множина натупльних чисел це така особлива множина, в якій кожний елемент має назву та порядок. За першим елементом йде другий, далі - третій, далі - четвертий.  
Дивовижною властивістю множини натуальних чисел є те, що назва елемента дорівнює кількості елементів до нього (включаючи нього).  
А якщо співставляйти множину натуальних чисел із якоюсь групою елементів, то кількість порахованих елементів буде дорівнювати номеру останнього.
