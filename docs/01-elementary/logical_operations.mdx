# Логічні операції
Зв'язок математики із філософією та найпростішими людськими операціями.

## Визначення відношення
До будь-якого об'єкта чи явища людина формує відношення: позитивне та негативне.  Якщо привести аналогію із одноклітинними організмами: позитивне - це поживні речовини, негативне - це отруйні речовини.  
Відповідно до  цієї ознаки клітина визначає власні дії - поживне їсть, від отруйного - тікає.  

## Логічні операції
НЕ отруйне = поживне  
НЕ поживне = отруйне  
  
Отруйне ТА Отруйне = Отруйне  
Поживне ТА Отруйне = Отруйне  
Отруйне ТА Поживне = Отруйне  
Поживне ТА Поживне = Поживне  
  
Отруйне АБО Отруйне = Отруйне  
Поживне АБО Отруйне = Поживне   
Отруйне АБО Поживне = Поживне    
Поживне АБО Поживне = Поживне   

Для того, щоб визначити відношення необхідно сфокусувати увагу на чомусь.
