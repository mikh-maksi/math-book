# Координатна пряма

Множину натуральних чисел можна відобразити як пряму із нанесеною на неї шкалою.  
Тоді для додавання одного числа до іншого треба відкласти на координатній прямій перше число, а далі  зробити праворуч кількість кроків, що дорівнює другому числу.  
Для віднмання другого числа від першого потрібно зробити відповідну кількість кроків ліворуч.
