# Множення як площа

Якщо ми хочемо помножити одне число на інше, то нам необхідно взяти прямоуктник, який складається з певної кількості одиничних прямокутників.  
При цьому ширина такого прямокутника має дорівнювати першому множинику, а висота - другому.  Результат добутку буде дорівнювати площі цього прямокутника.
