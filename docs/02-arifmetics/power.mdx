# Ступінь  
Степенем числа а з натуральним показником n (n > 1) називають добуток n множників, кожний з яких дорівнює а. 

Ступінь з основою $$а$$ і показником $$n$$ записують так: $$а^n$$, читають: «$$а$$ в степені $$n$$» або «$$n-й$$ степінь числа $$а$$»
$$a^2$$ називають квадратом числа $$а$$, $$а^3$$ називають кубом числа $$а$$.
