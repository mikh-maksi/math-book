# Тотожні перетворення
Вирази, відповідні значення яких є рівними при будь-яких значеннях змінних, що входять до них, називають **тотожно рівними**.  

Рівність, яка є правильною при будь-яких значеннях змінних, що входять до неї, називають **тотожністю**.
Заміну одного виразу іншим, тотожно рівним йому, називають **тотожним перетворенням виразу**.   
**Зведення подібних доданків** і **розкриття дужок** — приклади тотожних перетворень виразів.  
**Спрощення виразу** - це заміна його простішим (для вирішення, для сприйняття), тотожно рівним даному.  
  
## Методи тотожних перетворень:  
 1. Розкрити дужки. 
 2. Звести однотипні доданки. 
 3. Додати до лівої та правої частини рівності одне й те саме число. 
 4. Помножити та поділити ліву і праву частину рівності на одне й те саме число (за виключенням 0). 
 5. Перенести один з доданків через знак = (з лівої до правої частини рівності, або з правої до лівої частини рівності)

### Приклади тотожніх перетворень
|Первинне значення|Дія|Результат|
|---|---|---|
|$$ a - 15 = 0 $$ |Додамо до обидвох частин рівняння 15|$$ a = 15 $$|
|$$ a = 5 $$ |Помножимо обидві частини рівняння на -1|$$ -a = -5 $$|
|$$ \frac{a}{5}=1 $$ |Помножимо обидві частини рівняння на 5|$$ a = 5 $$|
|$$ 3(a+5)=1 $$|Розкриємо дужки|$$ 3a+15 = 1 $$|


### Приклад розкриття дужок та зведення доданків
|Первинне значення|Дія|Результат|
|---|---|---|
|$$ (a+2)(a+3)=0 $$ |Перемножимо всі складові дужок по черзі|$$ a^2+3a+2a+6 = 0 $$|
|$$ a^2+\underline{3a}+\underline{2a}+6 = 0 $$ |Перемножимо всі складові дужок по черзі|$$ a^2+5a+6 = 0 $$|


### Алгоритм вирішення рівнянь
|Первинне значення|Дія|Результат|
|---|---|---|
|$$ 3(a+2)-2(3a-6)=14+a $$|Розкриємо дужки|$$ 3a+6-6a+12=18+a $$|
|$$ \underline{3a}+6-\underline{6a}+12=14+\underline{a} $$|Зведемо подібні доданки|$$ \underline{-3a}+18=14+\underline{a} $$|
|$$ \underline{-3a}+18=14+\underline{a} $$|Перенесемо/залишимо всі елементи <br/> з a зліва від знаку =, а без а – справа|$$ -4a=-4 $$|
|$$ -4a=-4 $$|Ділимо обидві частини на значення <br/> (коефіцієнт, що стоїть при а) -4|$$ a=1 $$|
|$$ 3(a+2)-2(3a-6)=14+a $$|Підставляємо знайдене значення a=1 <br/> до первинного рівняння (для перевірки)|$$ 3(1+2)-2(3-6)=14+1 \\ 9+6=15 \\ 15=15$$|
