# Рівняння

**Рівняння** — це рівність, що містить позначене буквою невідоме число, яке потрібно знайти
Рівняння виду ax = b, де x — змінна, a і b — деякі числа, називають **лінійним рівнянням з однією змінною.**

## Розв’язання лінійних рівнянь
Розв’яжемо рівняння ax = b для різних значень a і b.
1) Якщо a ≠ 0, то, поділивши обидві частини рівняння ax = b на a, отримаємо $$x=\frac{b}{a}.$$ Тоді можна зробити такий висновок: 
якщо a ≠ 0, то рівняння ax = b має єдиний корінь, що дорівнює $$ \frac{b}{a} $$
